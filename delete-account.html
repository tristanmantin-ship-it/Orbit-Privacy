Orbit – Supprimer mon compte et mes données

Application : Orbit (fr.akkroma.orbit), éditée par Akkroma / Tristan Mantin.

Depuis l’application (recommandé)

  1. Ouvrez Orbit sur le téléphone du parent.
  2. Allez dans Réglages → Compte connecté → Supprimer mon compte.
  3. Choisissez si les comptes enfants doivent aussi être supprimés (à cocher si vous êtes le seul parent), tapez SUPPRIMER puis confirmez.

L’appareil de chaque enfant concerné est libéré : les restrictions sont levées.

Sans accès à l’application

Écrivez à tristan.mantin@outlook.fr depuis l’adresse e-mail du compte parent, avec pour objet « Suppression de compte Orbit ». Nous supprimons le compte sous 30 jours maximum et confirmons par e-mail.

Ce qui est supprimé

  • Le compte parent (authentification) et la famille.
  • Les enfants : prénom, avatar, dernière position, liste d’applications, statistiques d’usage, réseaux Wi-Fi, messages et commandes.
  • Le code parental et les codes d’association.

Ce qui est conservé

Rien n’est conservé après la suppression, hormis les journaux techniques de l’hébergeur (Cloudflare), conservés brièvement pour la sécurité. Les données stockées sur votre téléphone (photos, zones, contacts d’urgence) sont effacées en désinstallant l’application ou via « Réinitialiser Orbit ».
